# Provenance

The numerical `padconv.py`, both C kernels and extracted aeon kernel are byte-identical to the study's verified 2026-11-24 versions. Portable drivers change paths, output directories and integrity-manifest locations only. `Cc` in historical results is the paper's `P`; `Cc+L` is `P+L`.

Accuracy JSON files are copied unchanged. Timing and validation JSON files have local usernames and private filesystem prefixes replaced; numerical values are unchanged. Mac trained timing uses the complete idle-criterion rerun, not the earlier load-spike run. Random-head results are supplementary and must not be presented as trained-model accuracy. Historical full-data consistency checks are included; packaging checks do not replace those checks or new-host validation.

The paper manuscript, author correspondence, server access scripts, credentials, raw datasets and compiled binaries are excluded.
